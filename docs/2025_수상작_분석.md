## 2. 수상작 공통 패턴 요약

|---:|---|---|---|
| 1 | 운영 문제로 시작 | 에너지 비용, 소방자원 배치, 혼잡 안전 문제로 과제를 정의 | 산불 대응 자원 배치, 전력 인프라 점검, 고위험 격자 관리 문제로 정의 |

| 5 | 파생변수가 승부처 | Lag, 이동평균, 주기 인코딩, 체감지수, 특보, 외부 변수 | DWI, RNE, 실효습도, FMI, TMI, 전신주 수, 도로거리, 누적건조 변수 |
| 6 | 트리 기반 모델 선호 | XGBoost, LightGBM, CatBoost가 다수 사용 | 공식 FFDRI + LightGBM/XGBoost 보정 모델 |
| 7 | 단일 모델보다 분리·보정·앙상블 | 클러스터별 모델, 2-Stage, 잔차 보정, 극단값 분리 | 공식 FFDRI 재현 후 ML 보정, 고위험일/일반일 분리 가능 |
| 8 | 개선 효과를 단계별 비교 | 변수 추가 전후 RMSE, 모델별 RMSE, ablation table 제시 | DWI only → FFDRI → FFDRI+공간변수 → 보정모델 비교 |
| 9 | 활용 방안이 구체적 | 플랫폼, 대시보드, 인력 배치, 경고 시스템 제안 | 고위험 격자 지도, 전신주 점검 우선순위, 산불 감시 자원 배치 |

## 3. 패턴별 상세 분석 및 우리 프로젝트 적용

---

### 패턴 1. 모델보다 먼저 “운영 문제”를 정의한다

#### 수상작에서 나타난 방식

수상작들은 예측 자체보다 예측 결과가 해결하는 운영 문제를 먼저 제시한다.

| 보고서 | 직접 인용 | 해석 |
|---|---|---|
| 최우수상 주제1 열수요 | “정확한 열수요 예측은 매우 중요하다” | 열 생산량 과잉/부족이 비용 문제로 이어짐을 강조 |
| 우수상 주제2 119 신고 | “소방자원의 효율적 배치와 선제적 대응체계 구축” | 신고 예측을 공공 안전 운영 문제로 연결 |
| 최우수상 주제3 지하철 | “운영 효율성 및 이용자 편의성 향상” | 혼잡도 예측을 교통 운영·시민 편의 문제로 정의 |
| 특별상 주제2 119 신고 | “지능형 재난 대응 플랫폼 서비스 제안” | 단순 예측을 재난 대응 플랫폼으로 확장 |

#### 공통 구조

```text
기상 변화가 수요/위험을 흔든다
→ 예측이 가능하면 운영 비용, 안전, 자원 배치를 개선할 수 있다
→ 따라서 예측 모델이 필요하다
```

#### 우리 프로젝트 적용

산불 프로젝트도 다음과 같이 운영 문제로 정의하는 것이 좋다.

```text
산불위험은 단순한 기상 현상이 아니라,
기상·임상·지형·전력 인프라가 결합된 공간 위험 문제이다.

강원도 100m 격자 단위로 산불위험을 예측하면,
산불 감시 인력 배치, 전신주 주변 점검, 산불 대응 자원 사전 배치,
입산·소각 경고 등 실제 운영 의사결정에 활용할 수 있다.
```

#### 발표/보고서 문장 예시

> 본 연구는 강원도 100m 격자 단위의 기상·임상·지형·전력 인프라 데이터를 융합하여 산불 발생 위험을 정량화하고, 산불 감시 및 전력 시설 점검 우선순위 산정에 활용 가능한 예측 체계를 제안한다.

### 패턴 2. EDA는 그래프 나열이 아니라 모델링 전략의 근거다

#### 수상작에서 나타난 방식

| 보고서 | 직접 인용 | EDA에서 도출한 모델링 방향 |
|---|---|---|
| 최우수상 주제1 열수요 | “하절기에 비해 기온이 낮은 동절기에는 열 수요가 약 5배 이상” | 계절 스케일 차이 → Tweedie 손실, 계절성 변수 |
| 장려상 주제2 119 신고 | “평상시의 10-20배에 달하는 급격한 신고 건수 증가” | 극단값 존재 → 비선형 모델, 극단 구간 고려 |
| 특별상 주제2 119 신고 | “평상시의 안정적인 패턴과 … 극단값 패턴이 혼재” | 정상/극단 2-Stage 모델 |
| 최우수상 주제3 지하철 | “기상 변수 단독 분석의 한계” | 구조적 혼잡 패턴 제어 변수 추가 |

#### 공통 구조

수상작들은 EDA에서 다음 중 하나를 찾아낸다.

- 계절성
- 주기성
- 극단값
- 공간적 이질성
- 구조적 기본 패턴
- 단순 상관분석의 한계

그리고 이를 모델링 전략으로 연결한다.

#### 우리 프로젝트 적용

우리 산불 프로젝트에서 EDA는 다음 질문에 답해야 한다.

| EDA 질문 | 분석 방법 | 모델링 연결 |
|---|---|---|
| 산불 발생일의 FFDRI가 비발생일보다 높은가? | 발생일/비발생일 분포 비교 | 공식 FFDRI 타당성 검증 |
| 동해안과 내륙의 위험 패턴이 다른가? | 시군구별 평균 FFDRI, 발생 건수 비교 | 지역별 보정 필요성 |
| 고위험 격자가 실제 산불 발생지와 가까운가? | 발생 위치와 고위험 격자 거리 분석 | 공간 검증 |
| 임상·지형만으로 위험 설명이 가능한가? | FMI/TMI 단독 비교 | 기상+공간 결합 필요성 |
| 전신주 밀집 격자가 위험도와 겹치는가? | pole_count와 FFDRI 교차 분석 | 전력 인프라 관리 활용 |

#### 발표/보고서 문장 예시

> EDA 결과, 산불 위험은 산림 존재 여부만으로 설명되지 않았으며, 동해안 지역과 내륙 산악 지역 간 기상위험지수 분포에 뚜렷한 차이가 확인되었다. 이에 따라 본 연구에서는 기상지수뿐 아니라 임상, 지형, 접근성, 전력 인프라 특성을 함께 고려하였다.

### 패턴 3. 지역·지점·역·행정동별 이질성을 반드시 반영한다

#### 수상작에서 나타난 방식

| 보고서 | 직접 인용 | 적용 방식 |
|---|---|---|
| 우수상 주제1 열수요 | “지점별로 열수요 규모와 시간적 패턴이 상이” | branch_id별 K-Means 클러스터링 |
| 최우수상 주제1 열수요 | “동일한 기상 조건에서도 지사별로 상이한 열 수요” | 지사 정보 One-Hot Encoding |
| 장려상 주제3 지하철 | “유사한 추세를 보이는 역들을 3개의 클러스터로 분류” | 역별 혼잡 패턴 클러스터링 |
| 최우수상 주제2 119 신고 | “법정동 단위의 일별 119 신고 건수” | 법정동 단위 공간 특성 반영 |

#### 공통 구조

```text
전체를 하나로 보면 평균화되어 중요한 차이가 사라진다.
따라서 지역/지점/역/행정동 단위의 고유 패턴을 반영해야 한다.
```

#### 우리 프로젝트 적용

강원도 산불 프로젝트에서는 다음 방식 중 최소 하나를 적용하는 것이 좋다.

| 적용 방식 | 설명 | 난이도 |
|---|---|---|
| 시군구별 분석 | 강릉, 동해, 양양, 삼척, 고성, 홍천 등 시군구별 위험도 비교 | 낮음 |
| 동해안/내륙/산악권 구분 | 해안·산악·내륙 지역 특성 구분 | 낮음~중간 |
| 격자 클러스터링 | 평균 FFDRI, 습도, 풍속, 임상, 고도, 도로거리 기반 군집화 | 중간 |
| 지역별 모델 오차 분석 | 어느 지역에서 과소/과대 예측되는지 확인 | 중간 |

#### 우리 프로젝트 추천

우선순위는 다음과 같다.

1. 시군구별 FFDRI 평균 및 산불 발생 건수 비교
2. 동해안/내륙/산악권 권역 구분
3. 고위험 격자 클러스터링
4. 지역별 과소/과대 위험 평가

#### 발표/보고서 문장 예시

> 강원도는 동해안, 내륙 산악, 접경지역 등 지형·기상 조건이 상이하므로 단일 위험 기준만으로는 지역별 산불위험을 충분히 설명하기 어렵다. 이에 본 연구에서는 시군구 및 격자 단위의 공간 이질성을 반영하여 산불위험을 분석하였다.

### 패턴 4. 결측치 처리는 기술보다 “도메인 타당성”이 중요하다

#### 수상작에서 나타난 방식

| 보고서 | 직접 인용 | 결측치 처리 논리 |
|---|---|---|
| 최우수상 주제1 열수요 | “밤 시간대에는 물리적으로 0이어야” | 야간 일사량 결측은 0 대체 |
| 최우수상 주제3 지하철 | “시간적 연속성과 공간적 유사성” | 선형보간 + IDW 공간보간 |
| 최우수상 주제3 지하철 | “데이터 누수가 발생하기에 선형보간법을 적용하지 않음” | 테스트 데이터 누수 방지 |
| 최우수상 주제2 119 신고 | “단기 결측”과 “장기 결측” | 결측 길이에 따라 다른 보간 전략 |

#### 공통 구조

수상작들의 결측치 처리 원칙은 다음과 같다.

1. 결측값 표시값을 먼저 표준화한다.
2. 변수의 물리적 의미를 고려한다.
3. 시간적 연속성과 공간적 인접성을 활용한다.
4. 학습/검증/테스트 데이터 누수를 방지한다.
5. 보간 후 물리적으로 불가능한 값은 후처리한다.

#### 우리 프로젝트 적용

우리 프로젝트에서 강조할 수 있는 결측/전처리 논리는 다음과 같다.

| 변수/데이터 | 처리 논리 |
|---|---|
| 기온, 습도, 풍속 | 시간적 연속성이 있으므로 단기 결측 보간 가능 |
| 강수량 | 국지성이 강하므로 과도한 공간 보간보다 구간화·누적 효과 반영이 적합 |
| 풍향 | 0°와 360°가 같은 방향이므로 sin/cos 변환 필요 |
| 사면 방향 | 방향형 변수이므로 aspect_sin, aspect_cos로 연속성 보존 |
| 실효습도 | 당일과 과거 습도 영향을 함께 반영하는 도메인 지수 |
| RNE | 최근 강우가 산불위험을 낮추는 효과를 반영 |

#### 발표/보고서 문장 예시

> 풍향과 사면 방향은 0°와 360°가 동일한 원형 변수이므로 단순 수치형 각도로 사용할 경우 불연속성이 발생한다. 본 연구에서는 풍향과 사면 방향을 sin/cos 성분으로 변환하여 방향 정보의 연속성을 보존하였다.

### 패턴 5. 원본 변수보다 도메인 기반 파생변수가 중요하다

### 패턴 6. 모델은 XGBoost, LightGBM, CatBoost 계열이 주류다

#### 수상작에서 나타난 방식

| 보고서 | 직접 인용 | 모델 선택 |
|---|---|---|
| 최우수상 주제1 열수요 | “최종적으로 LightGBM Regressor를 채택” | LightGBM |
| 우수상 주제2 119 신고 | “최종적으로 XGBoost 모델을 선정” | XGBoost |
| 장려상 주제1 열수요 | “CatBoost 기반의 2-Stage” | CatBoost |
| 최우수상 주제3 지하철 | “최종 모델 : LightGBM” | LightGBM |

#### 공통 판단

수상작들은 딥러닝을 무조건 쓰지 않는다. 오히려 다음 이유로 트리 기반 모델을 많이 선택한다.

- 표 형식 데이터에 강함
- 결측/비선형/상호작용 처리에 유리함
- 변수 중요도 해석 가능
- 학습 속도가 빠름
- 적은 기간의 데이터에서도 안정적

#### 우리 프로젝트 적용

우리 프로젝트의 모델 구조는 다음 정도가 적합하다.

```text
1단계: 공식 FFDRI 산출
2단계: FFDRI와 실제 산불 발생 이력 비교
3단계: LightGBM 또는 XGBoost로 발생위험 보정 모델 학습
4단계: feature importance 또는 SHAP으로 해석
```

#### 추천 모델 우선순위

| 순위 | 모델 | 이유 |
|---:|---|---|
| 1 | Logistic Regression | 공식 산식과 비교하기 쉬운 해석형 기준선 |
| 2 | LightGBM | 대용량 격자 데이터에 적합, 빠름 |
| 3 | XGBoost | 안정적 성능, 수상작 다수 사용 |
| 4 | RandomForest | 간단한 비교 기준선 |

### 패턴 7. 단일 모델보다 분리·보정·앙상블 전략이 많다

#### 수상작에서 나타난 방식

| 장려상 주제1 열수요 | “잔차를 별도의 목표 변수로 설정” | 2-Stage 잔차 보정 |
| 최우수상 주제2 119 신고 | “LightGBM 기반의 잔차 보완 모델” | TFT + LGBM 하이브리드 |
| 장려상 주제3 지하철 | “각 군집마다 … XGBoost 회귀 모델” | 클러스터별 모델 |

```text
단일 모델로 모든 패턴을 설명하기 어렵다.

→ 1차 예측의 잔차를 보정하거나

```

#### 우리 프로젝트 적용

우리 프로젝트에서 가장 현실적인 구조는 **공식지수 재현 + ML 보정**이다.

```text
Stage 1. 공식 FFDRI 산출
- DWI, FMI, TMI, RNE, 일가중치 기반 공식 위험도 계산

Stage 2. 실제 산불 발생 이력 기반 보정
- FFDRI가 과소/과대평가하는 지역·시기 탐색
- LightGBM/XGBoost로 발생 여부 또는 발생확률 보정

Stage 3. 고위험 관리 격자 도출
- 공식 위험도 + 보정 위험도 + 전신주 밀집도 결합
```

#### 선택 가능한 확장

| 확장 전략 | 적용 가능성 |
|---|---|
| 발생일/비발생일 분리 | 가능 |
| 고위험일/일반일 분리 | 가능 |
| 동해안/내륙 모델 분리 | 가능 |
| 공식 FFDRI 잔차 보정 | 추천 |
| 앙상블 | 시간이 부족하면 생략 가능 |

#### 우리 프로젝트 적용

| 실험 | 입력 변수 | 목적 | 기대 해석 |

### 4.3 추천 분석 흐름

```text
1. 데이터 구축
   - master_grid + grid_date_master + 산불 발생 이력 결합

2. 공식 산불위험지수 재현
   - 실효습도 → PreDWI → Reclassified DWI → RNE → FFDRI
   - FMI, TMI, 일가중치 반영

3. EDA 및 타당성 검증
   - 발생일 vs 비발생일 FFDRI 비교
   - 시군구별 평균 FFDRI와 산불 발생 건수 비교
   - 고위험 격자와 실제 산불 발생 위치 비교

4. 보정 모델 개발
   - 입력: FFDRI, DWI, FMI, TMI, 기상, 임상, 지형, 전신주, 도로거리
   - 모델: Logistic Regression / LightGBM / XGBoost

5. 해석 및 활용
   - feature importance 또는 SHAP
   - 고위험 격자 지도
   - 전신주 점검 우선순위
   - 산불 대응 자원 배치 방안
```

## 7. 결론

2025년 수상작들은 공통적으로 다음 구조를 가진다.

```text
사회적·운영적 문제 정의
→ EDA로 데이터의 구조적 특징 발견
→ 도메인 지식 기반 전처리와 파생변수 생성
→ 지역/시간/극단성/이질성을 반영한 모델링
→ 성능 개선 근거 제시
→ 실제 정책·운영 활용 방안 제안
```

따라서 우리 프로젝트도 단순히 “산불 발생 예측 모델”로 접근하기보다,

```text
국가 산불위험지수 재현
+ 강원도 100m 격자 기반 검증
+ 실제 산불 발생 이력 기반 보정
+ 전신주/접근성 정보를 활용한 고위험 관리지역 도출
```

이라는 구조로 가져가는 것이 가장 설득력 있다.

최종적으로는 다음 메시지를 명확히 전달해야 한다.

> 본 연구는 기존 산불위험지수를 단순 적용하는 데 그치지 않고, 강원도 100m 격자 데이터와 실제 산불 발생 이력을 활용해 위험지수의 공간적 타당성을 검증하고, 전력 인프라 정보를 결합하여 현장 관리에 활용 가능한 고위험 격자를 도출하였다.
