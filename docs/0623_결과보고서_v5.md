## 1. 프로젝트 방향 전환 개요

본 프로젝트는 초기에는 산불 발생 여부를 직접 예측하는 지도학습 모델을 검토하였으나, 산불 미발생 격자를 실제 안전 지역으로 간주하기 어렵고, 산불 발생은 기상·지형·산림 조건뿐 아니라 발화원, 사람 활동, 좌표 품질, 우연성의 영향을 크게 받는다는 한계가 있었다.

이에 따라 본 연구의 분석 방향을 다음과 같이 재정의하였다.

> 산불 발생 여부를 직접 맞히는 지도학습 모델이 아니라, 봄철 산불위험기(2~5월)에 전력설비 주변 격자의 상대적 위험노출도와 점검 우선순위를 산정하는 위험도 스코어링 모델을 구축한다.

따라서 산불 발생 이력은 학습 타깃으로 사용하지 않고, 산출된 위험도 점수가 실제 산불 발생 위치 주변의 고위험 환경을 얼마나 포착하는지 확인하는 사후 검증 자료로만 활용하였다.

## 2. 분석 데이터 범위

본 프로젝트는 산불 위험이 특히 높아지는 봄철 산불위험기를 분석 대상으로 설정하였다.

- 분석 연도: 2020년 ~ 2025년
- 분석 월: 각 연도 2월 ~ 5월
- 검증 가능 연도: 2020년 ~ 2024년
- 운영 적용 해석 연도: 2025년

즉, 본 연구는 연중 전체 산불위험을 일반화하는 모델이 아니라, 봄철 산불위험기 전력설비 주변의 관리 우선순위를 산정하는 모델이다.

| 구분 | 내용 | 활용 목적 |
|---|---|---|
| `final_feature_daily` | 격자-일자 단위 최종 feature | grid-date 위험도 산정 |
| `master_grid.parquet` | 100m 격자 기준 공간 정보 | 좌표-grid 매핑, 지역 요약 |
| `test_hanjeon.csv` | 전신주 좌표 데이터 | 전신주별 위험도 산정 |
| `산불발생이력.csv` | 산불 발생 이력 | 2020~2024년 사후 검증 |

## 3. 1단계: 최종 전처리 산출물 품질 확인

기존 전처리 파이프라인으로 생성된 최종 feature 산출물을 재전처리하지 않고, 품질 확인 후 고정 입력으로 사용하였다.

초기 빠른 품질 확인에서는 실행 시간을 줄이기 위해 근사 집계를 사용하였고, 이로 인해 격자 수와 날짜 수가 실제 값과 다르게 산출되는 문제가 있었다. 이후 `10_check_final_feature_quality_v2.py`를 통해 정확한 `COUNT(DISTINCT grid_id)`, `COUNT(DISTINCT date)` 기준으로 재확인하였다.

### 3.1 정확한 전체 구조

| 항목 | 결과 |
|---|---:|
| 전체 row 수 | 197,106,722 |
| 정확한 격자 수 | 273,001 |
| 정확한 날짜 수 | 722 |
| 기대 row 수 | 197,106,722 |
| row 차이 | 0 |
| 날짜 범위 | 2020-02-01 ~ 2025-05-31 |
| `grid_id`, `date` 결측 | 없음 |
| `fire_label` 포함 여부 | 미포함 |

정확한 분석 기간은 2020~2025년 각 연도 2~5월이며, 전체 날짜 수는 722일이다.

```text
2020년 2~5월 = 121일
2021년 2~5월 = 120일
2022년 2~5월 = 120일
2023년 2~5월 = 120일
2024년 2~5월 = 121일
2025년 2~5월 = 120일
합계 = 722일
```

따라서 최종 feature 원본은 다음과 같은 균형 패널 구조로 확인되었다.

```text
273,001개 격자 × 722일 = 197,106,722 rows
```

### 3.2 최종 위험도 산정 대상

v5 최종 산식은 기상위험을 나타내는 `dwi`를 기준 위험도로 사용한다. 따라서 위험도 산정 대상은 `dwi` 유효 여부를 기준으로 판단하였다.

DWI 기반 산식은 다음 구조를 따른다.

```text
final_grid_risk
= 0.60 * dwi_pct
+ 0.25 * static_vulnerability
+ 0.15 * exposure_risk
```

11번 재실행 결과, 최종 grid-date 위험도는 원본 feature 전체 구조와 동일한 273,001개 격자와 722일, 총 197,106,722개 row에 대해 산출되었다. 즉, DWI 기반 위험도 산정 과정에서 제외된 grid-date 행은 발생하지 않은 것으로 확인된다.

### 3.3 품질 확인 결론

전처리 산출물은 다음 조건을 만족하므로 위험도 산정 입력으로 사용 가능하다고 판단하였다.

- `grid_id`, `date` 결측 없음
- 원본 feature가 `273,001개 격자 × 722일` 구조로 구성됨
- 산불 발생 여부 라벨인 `fire_label`이 포함되지 않음
- 최종 위험도 산정은 `dwi` 유효 행을 기준으로 수행함
- `slope_n`, `slope_pct`는 원본 컬럼에 없고, 원본에는 `slope`만 존재함
- 따라서 `slope_pct`는 11번 위험도 산정 코드에서 `slope`를 전체 grid 기준 percentile rank로 변환하여 내부 생성하는 파생변수로 해석함

## 4. 2단계: 위험도 산식 확정

본 연구의 위험도 산식은 산불 발생 확률을 직접 추정하는 확률모형이 아니라, 전력설비 주변 점검 우선순위를 산정하기 위한 도메인 기반 스코어링 모델이다.

최종 산식에서는 기상위험, 정적 취약도, 전력설비 노출도를 분리하여 반영하였다.

- `final_grid_risk`는 산불 발생 확률이 아니다.
- `final_grid_risk`는 동일 기간·동일 지역 내 상대적 위험노출도이다.
- 산불 이력은 학습 타깃이 아니라 사후 검증 자료이다.
- 최종 산식은 기상위험, 위치 취약성, 전력설비 노출도 세 축을 결합한다.

### 4.1 변수 정의

| 변수 | 의미 | 해석 방향 |
|---|---|---|
| `dwi` | 일별 기상위험 지표 | 값이 높을수록 해당 격자-일자의 기상 조건이 산불위험에 불리함 |
| `dwi_pct` | 같은 날짜 내 `dwi`의 percentile rank | 특정 날짜에서 상대적으로 기상위험이 높은 격자인지 나타냄 |
| `fmi_n` | 산림/연료 위험도를 정규화한 지표 | 산림 연료 조건상 취약성이 높을수록 값이 큼 |
| `tmi_p` | 지형 위험도 proxy 지표 | 지형 조건에 따른 산불 취약성을 반영 |
| `slope` | 원본 경사도 변수 | 원본 입력 컬럼으로 존재하는 경사 정보 |
| `slope_pct` | `slope`를 전체 grid 기준 percentile rank로 변환한 파생변수 | 원본 컬럼이 아니라 11번 코드 내부에서 생성되는 경사 위험도 보정항 |
| `road_prox` | 도로 인접성 또는 접근성 관련 지표 | 사람 활동 및 전력설비 접근 노출 요인을 반영 |
| `river_far` | 수계로부터의 이격 정도를 나타내는 지표 | 수계와 멀수록 건조·진화 접근성 측면에서 취약할 수 있음 |
| `static_raw` | 정적 취약도 구성 변수들의 가중합 | 위치 자체가 가진 산림·지형·접근성 취약성 |
| `static_vulnerability` | `static_raw`의 전체 grid 기준 percentile rank | 전체 격자 중 정적 취약성이 얼마나 높은지 의미 |
| `pei` | 전력설비 노출도 지표 | 전력설비 주변 노출도를 반영 |
| `exposure_risk` | `pei`의 전체 grid 기준 percentile rank | 전체 격자 중 전력설비 노출도가 얼마나 높은지 의미 |
| `final_grid_risk` | 최종 격자-일자 위험도 | 기상위험, 정적 취약도, 전력설비 노출도를 결합한 상대 위험노출도 |

특히 `slope_pct`는 원본 `final_feature_daily`에 저장된 컬럼이 아니다. 원본에는 `slope`만 존재하며, 11번 코드에서는 `slope`가 존재하는 경우 다음 방식으로 `slope_pct`를 내부 생성한다.

```text
slope_pct = PERCENT_RANK() OVER (ORDER BY slope)
```

따라서 보고서의 `static_raw` 산식에서 사용하는 `slope_pct`는 “원본 컬럼명”이 아니라 “경사도를 전체 grid 기준 percentile로 변환한 파생 지표”로 해석해야 한다.

### 4.2 Grid-date 위험도 산식

#### 4.2.1 기상 위험도

```text
dwi_pct = 같은 날짜 안에서 dwi의 percentile rank
```

날짜별 전체 기상위험 수준이 다르므로, 원점수보다 같은 날짜 안에서의 상대적 위치를 사용하였다.

#### 4.2.2 정적 취약도

```text
static_raw
= 0.400 * fmi_n
+ 0.350 * tmi_p
+ 0.100 * slope_pct
+ 0.075 * road_prox
+ 0.075 * river_far

static_vulnerability = static_raw의 전체 grid 기준 percentile rank
```

여기서 `slope_pct`는 원본 컬럼이 아니라 `slope`에서 파생한 percentile 지표이다.

#### 4.2.3 전력설비 노출도

```text
exposure_risk = pei의 전체 grid 기준 percentile rank
```

#### 4.2.4 최종 격자-일자 위험도

```text
final_grid_risk
= 0.60 * dwi_pct
+ 0.25 * static_vulnerability
+ 0.15 * exposure_risk
```

| 항목 | 가중치 | 설계 이유 |
|---|---:|---|
| 기상 위험도 | 0.60 | 산불위험의 일별 변동은 기상 조건에 크게 좌우됨 |
| 정적 취약도 | 0.25 | 같은 기상 조건에서도 산림, 지형, 경사, 접근성에 따라 위험도가 달라짐 |
| 전력설비 노출도 | 0.15 | 본 과제의 목적이 전력설비 주변 관리 우선순위 산정이므로 설비 노출도를 별도 반영 |

### 4.3 고위험 격자 정의

```text
daily_high_risk_flag = final_grid_risk가 해당 날짜 상위 5% 이내이면 1
```

일자별 점검·순찰 우선순위를 산정하기 위해 각 날짜별 상위 5% 격자를 고위험 후보군으로 정의하였다.

## 6. 4단계: 전신주 단위 risk score 산출

### 6.1 전신주-grid 매핑

전신주 좌표 데이터는 `pole_id`, `lon`, `lat`, `decision` 컬럼으로 구성되었다. 전신주에는 기존 `grid_id`가 없으므로, 좌표를 EPSG:5179로 변환한 뒤 100m 격자 기준으로 `grid_x`, `grid_y`를 계산하고 `master_grid`와 조인하여 `grid_id`를 부여하였다.

```text
grid_x = floor(x5179 / 100)
grid_y = floor(y5179 / 100)
```

| 항목 | 결과 |
|---|---:|
| 전신주 수 | 1,387,831 |
| grid 매핑 성공 | 1,387,783 |
| grid 매핑 실패 | 48 |
| 매핑률 | 99.9965% |
| 좌표 결측 | 0 |

전신주-grid 매핑률이 99.9965%로 매우 높게 나타나, 좌표 변환과 격자 매핑이 안정적으로 수행되었음을 확인하였다.

### 6.2 Grid-period risk 산출

| 항목 | 결과 |
|---|---:|
| grid 수 | 273,001 |
| 최소 grid period risk | 0.304048 |
| 평균 grid period risk | 0.620904 |
| 최대 grid period risk | 0.938560 |
| 관측 일수 | 722일 |

관측 일수 722일은 2020~2025년 각 연도 2~5월 날짜 수의 합과 일치한다.

### 6.3 전신주 위험도 산식

```text
pole_risk_score
= 0.50 * max_daily_risk
+ 0.30 * mean_top5_daily_risk
+ 0.20 * high_risk_day_ratio
```

| 항목 | 의미 |
|---|---|
| `max_daily_risk` | 분석 기간 중 해당 전신주가 속한 grid의 최대 일별 위험도 |
| `mean_top5_daily_risk` | 해당 grid의 위험도 상위 5일 평균 |
| `high_risk_day_ratio` | 해당 grid가 날짜별 상위 5% 고위험 격자에 포함된 날짜 비율 |

해당 산식은 단발성 고위험, 반복적 고위험, 고위험 지속성을 함께 반영하기 위한 구조이다.

## 8. 6단계: 산불 발생 이력 기반 사후 검증

### 8.1 검증 목적

본 검증은 지도학습 모델의 정확도 평가가 아니다. 산불 발생 이력은 학습에 사용하지 않았으며, 산출된 위험도 점수가 실제 산불 발생 위치 또는 그 주변의 고위험 환경을 얼마나 포착하는지 확인하는 사후 타당성 검증으로 활용하였다.

### 8.2 전국 산불 이력 사용 시 한계

산불 발생 이력 원자료는 전국 단위 자료이다. 따라서 강원권 전력설비 분석 격자와 무관한 산불이 다수 포함될 수 있다.

따라서 전국 이력 전체를 기준으로 검증하면, 본 연구의 분석 대상 지역과 맞지 않는 산불이 다수 포함되어 검증 표본 해석이 어려워진다.

### 8.3 강원권 산불 이력 필터링

이를 보완하기 위해 주소 정보에 다음 키워드가 포함된 산불 이력만 필터링하였다.

```text
강원, 강원도, 강원특별자치도
```

또한 exact grid만 보는 경우 좌표 오차와 100m 격자 경계 효과에 민감하므로, 산불 발생 좌표 주변 ±5격자, 즉 약 500m 권역을 함께 검증하였다.

## 10. 결과 해석 종합

본 연구는 기존의 산불 발생 여부 예측 문제를 전력설비 주변 위험도 우선순위 산정 문제로 재정의하였다. 그 결과 2020~2025년 2~5월 봄철 산불위험기 데이터를 기반으로 197,106,722개 격자-일자 조합에 대해 DWI 기반 `final_grid_risk`를 산출하였다.

이후 전신주 좌표를 100m 격자에 매핑하고, 격자별 기간 위험도를 집계하여 1,387,831개 전신주에 대한 `pole_risk_score`를 산출하였다. 최종적으로 위험도 상위 5%에 해당하는 69,390개 전신주를 `decision=1`로 분류하였다.

지역별 요약 결과, 고위험 전신주 절대 개수는 강릉시, 삼척시, 양양군 순으로 높게 나타났다. 상대 고위험 비율과 평균 위험도를 함께 고려하면 강릉시, 삼척시, 태백시, 동해시, 양양군 등이 봄철 전력설비 점검 우선순위가 높은 지역으로 해석된다.

산불 발생 이력 기반 사후 검증에서는 강원권 산불 이력 196건 중 147건이 산불 발생 좌표 주변 ±5격자 내에서 전력설비 분석 격자와 연결되었다. 이들에 대한 neighborhood 기준 검증 결과, 평균 최대 위험 percentile은 0.804973, top5 hit rate는 34.01%, top10 hit rate는 45.58%, top20 hit rate는 59.86%로 나타났다. 이는 산출된 위험도 점수가 실제 산불 발생 위치 주변의 고위험 환경을 일정 부분 포착하고 있음을 시사한다.

## 11. 한계 및 유의사항

1. **산불 발생 확률로 해석 불가**  
   `final_grid_risk`와 `pole_risk_score`는 산불 발생 확률이 아니라 상대적 위험노출도와 점검 우선순위를 산정하기 위한 스코어링 지표이다.

2. **가중치의 한계**  
   최종 위험도 산식의 가중치 0.60, 0.25, 0.15는 산불 이력으로 최적화된 계수가 아니라, 기상위험·정적 취약도·전력설비 노출도의 역할을 분리하기 위해 설정한 baseline 가중치이다.

3. **검증 표본의 제한**  
   산불 발생 이력은 전국 단위 자료이며, 본 연구의 위험도 산정 대상은 강원권 전력설비 분석 격자에 한정된다. 따라서 전국 산불 전체를 대상으로 한 예측 정확도 평가로 해석해서는 안 된다.

4. **Neighborhood 검증 해석의 한계**  
   주변 ±5격자 검증은 산불 발생 위치 주변의 고위험 환경을 포착했는지 확인하는 방법이다. 주변 500m 내 최대 위험 격자를 사용하는 구조이므로, 산불 발생 위치를 정확히 예측했다고 해석해서는 안 된다.

5. **지역별 결과 과대해석 주의**  
   일부 지역은 산불 검증 표본 수가 적다. 따라서 강릉시, 양양군 등 특정 지역의 높은 hit rate는 사례 분석으로 활용할 수 있으나, 지역 전체의 일반적 예측 성능으로 과대해석해서는 안 된다.

## 12. 향후 보완 방향

1. **가중치 민감도 분석**  
   `0.60/0.25/0.15` 외에도 여러 가중치 조합을 비교하여 산불 이력 검증 지표가 안정적으로 유지되는지 확인할 필요가 있다.

2. **반경별 검증 비교**  
   exact, ±1격자, ±5격자, ±10격자 등 반경별 hit rate를 비교하면 위험도 산식의 공간 포착 범위를 더 명확히 설명할 수 있다.

3. **전신주별 실제 점검·사고 데이터 연계**  
   향후 전력설비 점검 이력, 고장 이력, 산불 피해 설비 이력 등이 확보되면 `pole_risk_score`의 운영 타당성을 더 직접적으로 검증할 수 있다.

4. **시각화 보완**  
   고위험 전신주 분포, 강릉·삼척·양양·동해 등 주요 지역의 위험도 지도, 산불 발생 위치와 고위험 격자 중첩 지도를 생성하면 결과 해석력이 높아질 수 있다.

5. **의사결정 단위 명확화**  
   시군구별 요약은 정책적·설명적 자료로 사용하고, 실제 의사결정은 개별 전신주 단위 `pole_risk_score`와 `decision`을 기준으로 수행하는 것이 적절하다.

## 13. 결론

본 연구는 산불 발생 여부를 직접 예측하는 지도학습 모델 대신, 봄철 산불위험기 전력설비 주변의 상대적 위험노출도와 점검 우선순위를 산정하는 DWI 기반 스코어링 모델을 구축하였다.

최종적으로 2020~2025년 2~5월 격자-일자 단위 위험도, 전신주 단위 위험도, 시군구별 위험도 요약, 산불 발생 이력 기반 사후 검증까지 일관된 분석 흐름을 구성하였다.

특히 강원권 산불 이력 검증 결과, 산불 발생 좌표 주변 ±5격자 기준 top5 hit rate가 34.01%, 평균 최대 위험 percentile이 0.804973으로 나타나, 산출된 위험도 점수가 실제 산불 발생 위치 주변의 고위험 환경을 일정 부분 포착하고 있음을 확인하였다.

따라서 본 결과는 산불 발생 확률 예측 결과가 아니라, 제한된 점검·순찰 자원을 전력설비 주변 고위험 후보군에 우선 배분하기 위한 의사결정 지원 지표로 활용하는 것이 적절하다.

## 17. 발표·보고서에서 강조할 핵심 문장

1. 본 연구는 산불 발생 확률 예측 모델이 아니라 전력설비 주변 점검 우선순위 산정을 위한 위험도 스코어링 모델이다.

2. 산불 이력은 학습에 사용하지 않고, 산출 위험도가 실제 산불 발생 위치 주변의 고위험 환경을 포착하는지 확인하는 사후 검증 자료로만 활용하였다.

3. 최종 feature 원본은 273,001개 격자와 722일로 구성된 197,106,722개 row의 균형 패널 구조이며, 전체 grid-date 조합에 대해 DWI 기반 `final_grid_risk`를 산출하였다.

4. 최종 위험도 산식은 `0.60 * dwi_pct + 0.25 * static_vulnerability + 0.15 * exposure_risk`로 구성하였다.

5. 정적 취약도 산식의 `slope_pct`는 원본 컬럼이 아니라, 원본 `slope`를 전체 grid 기준 percentile rank로 변환한 파생 지표이다.

6. 1,387,831개 전신주 중 상위 5%인 69,390개를 우선 점검 후보군으로 분류하였다.

7. 시군구별로는 강릉시와 삼척시가 고위험 전신주 절대 개수와 상대 비율 모두 높은 지역으로 나타났다.

8. 강원권 산불 이력 검증 결과, 산불 발생 좌표 주변 ±5격자 기준 top5 hit rate가 34.01%로 나타나, 산출된 위험도가 실제 산불 발생 위치 주변의 고위험 환경을 일정 부분 포착함을 확인하였다.

9. 다만 본 결과는 산불 발생 위치를 정확히 예측했다는 의미가 아니라, 전력설비 주변 고위험 환경을 사전에 선별하기 위한 의사결정 지원 지표로 해석하는 것이 적절하다.
