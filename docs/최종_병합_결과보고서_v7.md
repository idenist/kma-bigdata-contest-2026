# 전력설비 주변 산불위험노출도 산정 및 Decision 분류 최종 병합 보고서

## 0. 최종 결론

본 프로젝트의 최종 제출 방향은 **DWI 기반 도메인 스코어링 모델(v6)**을 중심으로 설정한다.  
ML 기반 모델 비교, SHAP, Lift, Top-K 분석 결과는 최종 산식의 직접 산정 근거가 아니라, **위험도 산식에 포함된 기상·지형·접근성 요인의 타당성을 보조 검증하는 자료**로 활용한다.

최종 의사결정 구조는 다음과 같다.

| 구분 | 최종 적용 방향 | 해석 |
|---|---|---|
| 최종 모델 | DWI 기반 위험도 스코어링 모델 | 전력설비 주변 상대적 위험노출도 산정 |
| 최종 산출 단위 | 전신주 단위 | `pole_id`, `lon`, `lat`, `decision` 제출 구조와 직접 연결 |
| 최종 decision | `pole_risk_score` 상위 5%를 `decision=1` | 우선 점검·순찰 후보군 |
| ML 분석 역할 | 보조 검증 | 변수 타당성, Top-K 선별 논리, 해석 가능성 확인 |
| 최종 해석 | 산불 발생 확률 예측이 아니라 위험노출도 기반 이진분류 | 평가기준 부합성과 운영 활용성 동시 확보 |

본 보고서의 핵심 입장은 다음과 같다.

1. 본 과제의 핵심은 전신주별 `decision=0/1` 산출이므로, 최종 제출 모델은 전신주 단위 결과를 직접 생성하는 v6 스코어링 체계를 따른다.
2. `final_grid_risk`와 `pole_risk_score`는 산불 발생 확률이 아니라, 동일 기간·동일 지역 내 상대적 위험노출도 및 점검 우선순위 지표로 해석한다.
3. 산불 발생 이력은 최종 위험도 산식 학습에 사용하지 않고, 산출된 위험도가 실제 산불 위치 주변의 고위험 환경을 포착하는지 확인하는 사후 검증 자료로만 활용한다.
4. ML에서 확인된 중요 변수는 v6 산식의 직접 가중치 근거가 아니라, 기상위험·정적 취약도·접근성 요인의 방향성이 데이터 기반 분석과 충돌하지 않는다는 보조 근거로 사용한다.
5. 평가기준상 정량 F1 score와 정성 평가가 모두 존재하므로, 제출 파일 규격 준수, 산식 합리성, 데이터 분석 절차, 활용 가능성, 검증 논리를 함께 제시한다.

## 1. 공모 요건 및 평가기준 대응

### 1.1 공모 주제 해석

공모 주제는 **기상 데이터 및 공간정보 기반 전력설비 인근 화재 위험도 분석**이다. 분석 내용은 강원 지역 내 가상 전력설비 위치정보와 기상 데이터를 활용하여 전력설비 주변의 화재 위험 발생 여부를 이진분류하는 것이다.

따라서 본 프로젝트는 단순한 산불 발생 위치 예측 문제가 아니라, 다음 질문에 답하는 문제로 정의한다.

> 강원 지역 전력설비 주변에서 기상·지형·산림·접근성·전력설비 노출 조건을 종합했을 때, 어느 전신주가 상대적으로 더 높은 화재위험노출도에 놓여 있는가?

이에 따라 최종 `decision`은 다음과 같이 해석한다.

| decision | 의미 | 운영 해석 |
|---:|---|---|
| 1 | 상대적 위험노출도가 높은 전신주 | 우선 점검·순찰 후보 |
| 0 | 상대적 위험노출도가 낮거나 일반 관리 대상인 전신주 | 일반 후보 |

중요한 점은 `decision=1`이 “해당 전신주에서 반드시 산불이 발생한다”는 뜻이 아니라는 점이다.  
`decision=1`은 제한된 점검 자원을 우선 배분하기 위한 **상대적 고위험 후보군**이다.

### 1.2 제출 파일 규격 대응

최종 제출 파일은 다음 구조를 따른다.

```text
pole_id, lon, lat, decision
```

| 컬럼 | 의미 | 본 프로젝트 처리 방식 |
|---|---|---|
| `pole_id` | 전력설비 지점 ID | 원본 전신주 데이터 유지 |
| `lon` | 경도 | 원본 좌표 유지 |
| `lat` | 위도 | 원본 좌표 유지 |
| `decision` | 이진분류 결과 | `pole_risk_score` 기준 상위 5%를 1로 분류 |

최종 제출에 가장 가까운 산출물은 다음 파일이다.

```text
output/risk/test_hanjeon_with_decision.csv
```

## 2. 분석 방향 전환 및 최종 모델 정의

### 2.1 기존 지도학습 접근의 한계

초기에는 산불 발생 여부를 직접 예측하는 지도학습 모델을 검토하였다. 그러나 산불 발생 여부를 직접 타깃으로 삼는 방식에는 다음 한계가 있다.

1. 산불 미발생 격자를 실제 안전 지역으로 간주하기 어렵다.
2. 산불 발생은 기상·산림·지형 조건뿐 아니라 발화원, 사람 활동, 진화 여건, 신고 위치, 좌표 품질, 우연성의 영향을 크게 받는다.
3. 산불 발생 grid-day는 전체 후보에 비해 매우 희소하여 precision과 F1이 불안정할 수 있다.
4. 전력설비 주변 관리 목적에서는 특정 지점의 발생 확률보다, 우선 점검 후보군을 얼마나 합리적으로 선별하는지가 더 중요하다.

따라서 본 프로젝트는 다음과 같이 분석 목적을 재정의하였다.

> 산불 발생 여부를 직접 맞히는 확률 예측 모델이 아니라, 봄철 산불위험기 전력설비 주변의 상대적 위험노출도와 점검 우선순위를 산정하는 위험도 스코어링 모델을 구축한다.

### 2.2 최종 모델의 성격

최종 모델은 **DWI 기반 도메인 스코어링 모델**이다.

이 모델은 `fire_label`을 학습 타깃으로 사용하지 않는다. 대신 기상위험, 정적 취약도, 전력설비 노출도를 결합하여 격자-일자 단위 위험도인 `final_grid_risk`를 산출한다. 이후 전신주가 속한 격자의 기간 위험도를 집계하여 `pole_risk_score`를 만들고, 상위 5% 전신주를 `decision=1`로 분류한다.

| 단계 | 산출물 | 역할 |
|---|---|---|
| 1 | `final_grid_risk` | 격자-일자 단위 상대 위험노출도 |
| 2 | `daily_high_risk_flag` | 일자별 상위 5% 고위험 격자 여부 |
| 3 | `pole_risk_score` | 전신주 단위 기간 위험도 |
| 4 | `decision` | 제출용 이진분류 결과 |

### 2.3 최종 모델과 ML 분석의 관계

최종 보고서에서는 v6 스코어링 모델과 ML 분석을 다음처럼 구분한다.

| 구분 | v6 스코어링 모델 | ML 모델 분석 |
|---|---|---|
| 주 역할 | 최종 제출 decision 생성 | 보조 검증 및 해석 가능성 확인 |
| label 사용 | 사용하지 않음 | `fire_label` 기반 지도학습 |
| 산출 단위 | 전신주 | grid-day 또는 해상도별 모델 |
| 주요 결과 | `pole_risk_score`, `decision` | Top-K, Lift, SHAP, 모델 비교 |
| 보고서 내 위치 | 본 방법론 | 보조 분석 |
| 해석상 주의 | 산불 발생 확률 아님 | v6 가중치 직접 근거 아님 |

따라서 ML 분석 결과를 다음과 같이 사용하지 않는다.

```text
ML SHAP 결과를 기반으로 v6 최종 가중치 0.60/0.25/0.15를 산정하였다.
```

대신 다음과 같이 사용한다.

```text
ML 기반 중요도 분석에서 습도, DWI, 바람, 강수, 지형, 수계 접근성 등이 주요 변수로 확인되었으며,
이는 v6 위험도 산식의 기상위험·정적 취약도·접근성 구성과 개념적으로 부합한다.
따라서 ML 분석은 최종 산식의 직접 가중치 근거가 아니라 변수 구성 타당성을 보조 확인하는 자료로 활용하였다.
```

최종 feature는 기존 전처리 파이프라인으로 생성된 산출물을 재전처리하지 않고, 품질 확인 후 고정 입력으로 사용하였다.

| 항목 | 결과 |
|---|---:|
| 전체 row 수 | 197,106,722 |
| 정확한 격자 수 | 273,001 |
| 정확한 날짜 수 | 722 |
| 기대 row 수 | 197,106,722 |
| row 차이 | 0 |
| 날짜 범위 | 2020-02-01 ~ 2025-05-31 |

분석 기간별 날짜 수는 다음과 같다.

```text
2020년 2~5월 = 121일
2021년 2~5월 = 120일
2022년 2~5월 = 120일
2023년 2~5월 = 120일
2024년 2~5월 = 121일
2025년 2~5월 = 120일

```

따라서 최종 feature는 다음 균형 패널 구조를 가진다.

```text
273,001개 격자 × 722일 = 197,106,722 rows
```

품질 확인 결과, `grid_id`, `date` 결측이 없고 전체 grid-date 조합이 기대 구조와 일치하므로 위험도 산정 입력으로 사용할 수 있다고 판단하였다.

## 4. 최종 위험도 산식

### 4.1 산식 설계 원칙

최종 위험도 산식은 산불 발생 확률을 직접 추정하는 확률모형이 아니다.  
전력설비 주변 점검 우선순위를 산정하기 위한 도메인 기반 스코어링 모델이다.

최종 산식은 다음 세 축을 결합한다.

| 축 | 의미 | 역할 |
|---|---|---|
| 기상위험 | 일별 산불위험을 높이는 기상 조건 | 시간적 변동성 반영 |
| 정적 취약도 | 산림·지형·접근성 등 위치 자체의 취약성 | 공간적 취약성 반영 |
| 전력설비 노출도 | 전력설비 주변 노출 특성 | 공모 주제 부합성 반영 |

### 4.2 변수 정의

| 변수 | 의미 | 해석 방향 |
|---|---|---|
| `dwi` | 일별 기상위험 지표 | 값이 높을수록 해당 격자-일자의 기상 조건이 산불위험에 불리함 |
| `dwi_pct` | 같은 날짜 내 `dwi` percentile rank | 해당 날짜에서 상대적으로 기상위험이 높은 격자인지 표시 |
| `fmi_n` | 산림·연료 위험도 정규화 지표 | 산림 연료 조건상 취약성이 높을수록 값이 큼 |
| `tmi_p` | 지형 위험도 proxy 지표 | 지형 조건에 따른 산불 취약성 반영 |
| `slope` | 원본 경사도 변수 | 원본 입력 컬럼 |
| `slope_pct` | `slope`의 percentile rank | 경사 위험도 보정항, 원본 컬럼이 아니라 파생변수 |
| `road_prox` | 도로 인접성 또는 접근성 지표 | 사람 활동 및 접근 노출 요인 반영 |
| `river_far` | 수계 이격 지표 | 수계와 멀수록 건조·진화 접근성 측면에서 취약할 수 있음 |
| `static_vulnerability` | 정적 취약도 | 산림·지형·접근성 취약성 통합 |
| `pei` | 전력설비 노출도 지표 | 전력설비 주변 노출도 반영 |
| `exposure_risk` | `pei` percentile rank | 전체 격자 중 전력설비 노출도가 높은 정도 |
| `final_grid_risk` | 최종 격자-일자 위험도 | 세 위험 축을 결합한 상대 위험노출도 |

`slope_pct`는 원본 컬럼이 아니다. 원본에는 `slope`만 존재하며, 위험도 산정 단계에서 다음 방식으로 내부 생성한다.

```text
slope_pct = PERCENT_RANK() OVER (ORDER BY slope)
```

### 4.3 기상 위험도

기상 위험도는 `dwi`를 같은 날짜 내 percentile rank로 변환한 `dwi_pct`를 사용한다.

```text
dwi_pct = 같은 날짜 안에서 dwi의 percentile rank
```

날짜마다 전체 기상위험 수준이 다르기 때문에 원점수보다 같은 날짜 안에서의 상대적 위치를 사용하였다. 이는 특정 날짜에 어느 격자가 상대적으로 더 위험한 조건에 놓였는지 판단하기 위한 방식이다.

### 4.4 정적 취약도

정적 취약도는 산림, 지형, 경사, 접근성 요인을 결합한다.

```text
static_raw
= 0.400 * fmi_n
+ 0.350 * tmi_p
+ 0.100 * slope_pct
+ 0.075 * road_prox
+ 0.075 * river_far

static_vulnerability = static_raw의 전체 grid 기준 percentile rank
```

정적 취약도는 시간에 따라 크게 변하지 않는 위치 기반 취약성을 표현한다. 같은 기상 조건이라도 산림 연료, 지형, 경사, 도로·수계 접근성에 따라 실제 위험노출도는 달라질 수 있으므로 별도 축으로 반영하였다.

### 4.5 전력설비 노출도

전력설비 노출도는 `pei`를 전체 grid 기준 percentile rank로 변환해 사용한다.

```text
exposure_risk = pei의 전체 grid 기준 percentile rank
```

본 과제의 목적이 전력설비 주변 화재위험도 분석이므로, 전력설비 노출 요인을 별도 축으로 반영하였다.

### 4.6 최종 격자-일자 위험도

최종 격자-일자 위험도는 다음과 같다.

```text
final_grid_risk
= 0.60 * dwi_pct
+ 0.25 * static_vulnerability
+ 0.15 * exposure_risk
```

| 항목 | 가중치 | 설계 이유 |
|---|---:|---|
| 기상 위험도 | 0.60 | 산불위험의 일별 변동은 기상 조건에 크게 좌우됨 |
| 정적 취약도 | 0.25 | 같은 기상 조건에서도 산림, 지형, 경사, 접근성에 따라 위험도가 달라짐 |
| 전력설비 노출도 | 0.15 | 전력설비 주변 관리 우선순위 산정이라는 과제 목적 반영 |

### 4.7 고위험 격자 정의

일자별 점검·순찰 우선순위를 산정하기 위해 각 날짜별 상위 5% 격자를 고위험 후보군으로 정의하였다.

```text
daily_high_risk_flag = final_grid_risk가 해당 날짜 상위 5% 이내이면 1
```

## 8. 산불 발생 이력 기반 사후 검증

### 8.1 검증 목적

본 검증은 지도학습 모델의 정확도 평가가 아니다. 산불 발생 이력은 위험도 산식 학습에 사용하지 않았으며, 산출된 위험도 점수가 실제 산불 발생 위치 또는 그 주변의 고위험 환경을 얼마나 포착하는지 확인하는 사후 타당성 검증으로 활용하였다.

### 8.2 강원권 산불 이력 필터링

산불 발생 이력 원자료는 전국 단위 자료이므로, 강원권 전력설비 분석 격자와 무관한 산불이 포함될 수 있다. 따라서 주소 정보에 다음 키워드가 포함된 산불 이력만 필터링하였다.

```text
강원, 강원도, 강원특별자치도
```

또한 exact grid만 보는 경우 좌표 오차와 100m 격자 경계 효과에 민감하므로, 산불 발생 좌표 주변 ±5격자, 즉 약 500m 권역을 함께 검증하였다.

## 9. ML 기반 보조 검증 결과

### 9.1 ML 분석을 보조 검증으로 활용하는 이유

별도로 수행한 ML 분석은 최종 제출 모델을 대체하기 위한 것이 아니라, 다음 목적을 위해 활용한다.

1. 도메인 기반 위험도 산식이 데이터 기반 변수 중요도와 충돌하지 않는지 확인한다.
2. 산불위험도 판단에서 중요한 기상·지형·접근성 변수가 실제로 상위에 나타나는지 확인한다.
3. Top-K, Lift 분석을 통해 상위 위험군 선별 논리를 보강한다.
4. SHAP 및 중요도 분석을 통해 설명 가능성을 확보한다.

즉, ML 분석은 **최종 산식의 직접 가중치 근거가 아니라 보조 검증 자료**이다.

### 9.2 ML 모델 비교 요약

ML 모델 비교에서는 500m와 1km 해상도에서 Logistic Regression, RandomForest, XGBoost, LightGBM을 비교하였다.

| 구분 | 모델 | 해석 |
|---|---|---|
| 2023 full validation 기준 우수 모델 | `logistic_regression/1km` | 사전에 정한 validation 기준에서 우수 |
| 2024 full test 기준 우수 대안 | `random_forest/1km` | 사후 일반화 성능이 우수 |
| 최종 보고서 내 역할 | 보조 검증 | v6 산식의 변수 타당성과 ranking 논리 보강 |

2023 validation 기준에서는 `logistic_regression/1km`가 Recall@Top10000 기준으로 가장 우수하였다. 2024 test에서는 `random_forest/1km`가 Top-K 성능에서 우수하였다. 그러나 2024 결과를 보고 최종 모델을 바꾸면 test leakage 논란이 발생할 수 있으므로, ML 분석 내에서도 validation/test 분리 원칙을 유지하였다.

본 최종 병합 문서에서는 이 ML 결과를 **제출 모델 선정 근거**로 쓰지 않고, **v6 산식의 보조 검증 근거**로만 사용한다.

### 9.3 ML에서 확인된 주요 변수

ML 기반 SHAP 및 중요도 분석에서는 해상도와 모델이 달라도 다음 변수들이 반복적으로 중요하게 나타났다.

| 그룹 | 주요 변수 | 해석 |
|---|---|---|
| 습도 | `effective_humidity`, `hm_mean`, `hm_min` | 건조·습도 조건이 산불위험 판단에 중요 |
| 기상위험지수 | `dwi`, `dwi_n`, `ffdri` | DWI 계열 지표가 위험도 판단에 기여 |
| 바람 | `wind_ws_mean`, `wind_ws_max`, `Ws` | 강풍 조건이 위험 확산 환경과 관련 |
| 강수 | `rn_day_mean`, `rn_day_max`, `rne` | 강수 부족 및 건조 환경 반영 |
| 지형 | `elevation`, `tmi_base_n` | 지형 조건이 위험도 판단에 기여 |

RandomForest 1km SHAP 중요도 상위 변수에서도 `effective_humidity`, `hm_mean`, `dwi`, `wind_ws_max`, `rn_day_mean`, `elevation`, `rn_day_max`, `hm_min`, `wind_ws_mean` 등이 상위에 나타났다.

이는 v6의 위험도 산식이 기상위험, 정적 취약도, 접근성 요인을 포함하는 방향과 개념적으로 부합한다.

### 9.4 ML 피처와 v6 산식의 연결 관계

ML에서 확인된 피처와 v6 산식은 이름과 단위가 동일하지 않다. 따라서 직접 대응시키면 안 된다. 대신 다음처럼 개념적 축으로 연결한다.

따라서 최종 보고서에서는 다음 표현을 사용한다.

```text

```

### 9.5 Accuracy보다 Top-K, Lift가 중요한 이유

산불 발생 grid-day는 전체 grid-day에 비해 매우 희소하다. 이런 경우 모든 후보를 “산불 없음”으로 예측해도 accuracy가 높게 나올 수 있다. 따라서 accuracy는 본 프로젝트의 핵심 지표로 적절하지 않다.

본 프로젝트의 운영 시나리오는 다음과 같다.

> 모든 전신주를 동일하게 점검하는 것이 아니라, 위험도 상위 후보군을 우선 점검한다.

따라서 ML 분석에서는 다음 지표가 더 적절하다.

| 지표 | 역할 |
|---|---|
| Top-K recall | 상위 위험 후보군 안에 실제 산불 발생 grid-day가 얼마나 포함되는지 확인 |
| Lift | 상위 위험군이 무작위보다 실제 산불 발생 밀도를 얼마나 높게 포착하는지 확인 |
| PR-AUC | positive가 희소한 불균형 데이터에서 보조 성능 확인 |
| SHAP | 모델이 어떤 변수에 반응했는지 설명 |

이 논리는 v6의 상위 5% `decision=1` 기준과도 연결된다. 상위 후보군을 운영 대상으로 선별한다는 점에서, Top-K와 Lift는 정밀한 발생 확률보다 운영 우선순위 관점에 더 가깝다.

## 12. 평가기준별 최종 방어 논리

### 12.1 모델 예측 정확성

정량 평가는 제출 CSV의 `decision` 기준 F1 score로 평가된다. 본 프로젝트는 `pole_risk_score`를 기반으로 상위 5% 전신주를 `decision=1`로 분류하였다.

방어 논리는 다음과 같다.

1. 산불 발생 여부를 직접 학습하지 않았으므로 hidden label에 과적합할 가능성을 낮췄다.
2. 전신주 단위 제출 규격에 맞춰 최종 decision을 직접 산출하였다.
3. 강원권 산불 이력 기반 사후 검증에서 실제 산불 위치 주변의 고위험 환경을 random baseline보다 더 잘 포착하였다.
4. 상위 5% 기준은 모든 후보를 위험으로 분류하는 방식이 아니라, 제한된 점검 자원에서 우선관리 후보를 선별하는 운영 기준이다.

단, 실제 F1 최적화를 위해서는 제출 전 threshold 후보별 내부 비교가 가능하다면 추가 점검하는 것이 바람직하다. 다만 사후 산불 이력에 과도하게 맞춘 threshold 조정은 과적합 위험이 있으므로 주의해야 한다.

### 12.2 합리성

최종 모델은 기상위험, 정적 취약도, 전력설비 노출도를 분리하여 반영한다. 이는 산불위험이 단일 원인으로 설명되지 않고, 일별 기상 조건과 위치 기반 취약성, 전력설비 노출 조건이 결합되어 나타난다는 점을 반영한 구조이다.

특히 `final_grid_risk`를 산불 발생 확률로 해석하지 않고 상대적 위험노출도로 정의함으로써, 실제 산불 발생의 우연성과 발화원 요인을 과도하게 단순화하지 않았다.

### 12.3 데이터 분석능력

본 프로젝트는 다음 분석 절차를 수행하였다.

1. 197,106,722개 grid-date feature 구조 품질 확인

## 13. 한계 및 유의사항

### 13.1 산불 발생 확률로 해석 불가

`final_grid_risk`와 `pole_risk_score`는 산불 발생 확률이 아니다.  
동일 기간·동일 지역 내 상대적 위험노출도와 점검 우선순위를 산정하기 위한 스코어링 지표이다.

### 13.2 가중치의 한계

최종 가중치 `0.60/0.25/0.15`는 산불 이력으로 최적화된 계수가 아니라, 기상위험·정적 취약도·전력설비 노출도의 역할을 분리하기 위해 설정한 baseline 가중치이다. 민감도 분석을 통해 안정성을 확인했지만, 절대적으로 최적인 가중치라고 해석해서는 안 된다.

### 13.3 산불 이력 검증의 한계

산불 발생 이력은 전국 단위 자료이며, 본 연구의 위험도 산정 대상은 강원권 전력설비 분석 격자에 한정된다. 따라서 전국 산불 전체에 대한 예측 정확도 평가로 해석해서는 안 된다.

### 13.4 Neighborhood 검증 해석의 한계

Neighborhood 검증은 산불 발생 위치 주변 관리권역에 고위험 환경이 존재하는지 확인하는 방식이다. 주변 여러 격자 중 하나라도 고위험 격자가 있으면 hit로 계산되므로, 단순 5%, 10%, 20% 기준과 직접 비교하면 과대해석 위험이 있다. 따라서 random-neighborhood baseline 대비 차이와 lift를 함께 해석해야 한다.

### 13.5 ML 분석 결과 사용 시 주의

ML에서 확인된 중요 변수와 v6 산식의 구성 변수는 동일하지 않다. 예를 들어 ML에서는 `effective_humidity`가 중요하게 나타났지만, v6 최종 산식은 `dwi_pct`를 기상위험 대표 지표로 사용한다.

따라서 ML 결과는 다음 용도로만 사용한다.

```text
가능한 사용:
- v6 산식의 변수 구성 방향성 검토
- 기상·지형·접근성 요인의 타당성 보조 확인
- Top-K 및 Lift 기반 상위 위험군 선별 논리 보강

피해야 하는 사용:
- ML SHAP 결과로 v6 가중치를 산정했다고 주장

- ML의 fire_label 기반 검증과 v6의 라벨 비사용 산식을 혼동
```

## 14. 최종 보고서용 핵심 문장

### 14.1 연구 목적 문장

본 연구는 산불 발생 여부를 직접 확률 예측하는 모델이 아니라, 강원 지역 가상 전력설비 주변의 기상위험, 정적 취약도, 전력설비 노출도를 결합하여 전신주별 화재위험노출도를 산정하고, 상위 위험 후보를 `decision=1`로 분류하는 의사결정 지원 모델을 구축하였다.

### 14.2 최종 산식 문장

최종 격자-일자 위험도는 일별 기상위험을 나타내는 `dwi_pct`, 위치 기반 취약성을 나타내는 `static_vulnerability`, 전력설비 노출도를 나타내는 `exposure_risk`를 결합하여 산정하였다.

```text
final_grid_risk
= 0.60 * dwi_pct
+ 0.25 * static_vulnerability
+ 0.15 * exposure_risk
```

### 14.3 전신주 decision 문장

격자-일자 위험도는 전신주가 속한 grid 단위로 집계하였고, 최대 일별 위험도, 상위 5일 평균 위험도, 고위험 지속일 비율을 결합하여 `pole_risk_score`를 산출하였다. 최종적으로 `pole_risk_score` 상위 5%에 해당하는 69,390개 전신주를 `decision=1`로 분류하였다.

### 14.4 검증 문장

강원권 산불 이력 기반 사후 검증 결과, 산불 발생 좌표 주변 ±5격자 기준 top5 hit rate는 34.01%였으며, 동일 날짜·동일 반경의 random-neighborhood baseline은 24.92%로 나타났다. 이는 산출된 위험도 점수가 실제 산불 발생 위치 주변의 고위험 환경을 무작위 위치보다 더 잘 포착하고 있음을 시사한다.

### 14.5 ML 보조검증 문장

별도로 수행한 ML 기반 SHAP 및 중요도 분석에서는 습도, DWI, 바람, 강수, 지형, 수계 접근성 등이 주요 변수로 확인되었다. 이는 최종 스코어링 산식에 포함된 기상위험·정적 취약도·접근성 요인과 개념적으로 부합한다. 다만 ML 분석 결과는 최종 산식의 직접 가중치 산정 근거가 아니라, 변수 구성과 위험도 해석의 타당성을 보조적으로 확인하는 근거로 활용하였다.

### 14.6 활용 문장

본 결과는 산불 발생 위치를 정확히 예측했다는 의미가 아니라, 전력설비 주변 고위험 환경을 사전에 선별하고 제한된 점검·순찰 자원을 우선 배분하기 위한 의사결정 지원 지표로 활용하는 것이 적절하다.

## 15. 발표 및 질의응답 대응

### 15.1 “왜 ML 최종모델이 아니라 v6 스코어링을 최종으로 선택했는가?”

공모 제출 단위는 전신주별 `pole_id`, `lon`, `lat`, `decision`이다. ML 모델은 grid-day 기반 위험도와 변수 중요도 검토에는 유용하지만, 최종 제출 파일을 직접 생성하는 구조는 v6 스코어링 모델이 더 명확하다. 따라서 최종 제출은 v6 스코어링 모델로 수행하고, ML 분석은 변수 타당성과 상위 위험군 선별 논리를 보조 검증하는 자료로 활용하였다.

### 15.2 “산불 발생을 예측한 것인가?”

아니다. 본 모델은 산불 발생 확률을 직접 예측하는 모델이 아니라, 전력설비 주변의 상대적 화재위험노출도와 점검 우선순위를 산정하는 모델이다. 산불 발생에는 발화원, 사람 활동, 진화 여건, 좌표 품질, 우연성 등 외부 요인이 크게 작용하므로, 본 연구에서는 발생 확률보다 위험환경 선별에 초점을 두었다.

### 15.3 “왜 상위 5%를 decision=1로 했는가?”

전력설비 점검·순찰은 모든 전신주를 동일하게 관리하기 어렵기 때문에, 상대적으로 위험노출도가 높은 후보군을 우선 선별해야 한다. 상위 5% 기준은 제한된 점검 자원을 고려한 운영형 threshold이며, 일자별 고위험 격자 정의와 전신주 단위 우선관리 후보군 선정에 일관되게 적용하였다.

### 15.4 “ML에서 중요한 피처와 v6 산식 피처가 다른데 문제없는가?”

문제없다. 다만 같은 모델의 같은 피처처럼 해석하면 안 된다. ML 분석은 `fire_label` 기반 지도학습에서 어떤 변수가 위험도 판단에 영향을 주는지 확인한 보조 분석이다. v6 산식은 도메인 기반 스코어링 모델이며, `dwi_pct`, `static_vulnerability`, `exposure_risk`처럼 집계·파생 지표를 사용한다. 따라서 ML 결과는 v6 가중치 산정 근거가 아니라, 기상·지형·접근성 요인의 타당성을 보조 확인하는 자료로 사용하였다.

### 15.5 “Neighborhood hit rate 34.01%를 5%와 직접 비교해도 되는가?”

직접 비교하면 안 된다. Neighborhood 검증은 주변 여러 격자 중 하나라도 top5 격자가 있으면 hit로 계산되므로, 반경이 커질수록 random 위치에서도 hit rate가 증가한다. 따라서 본 연구에서는 동일 날짜·동일 반경 random-neighborhood baseline을 구성했고, ±5격자 기준 실제 top5 hit rate 34.01%와 random baseline 24.92%를 비교하여 +9.09%p 차이와 1.36배 lift를 확인하였다.

## 16. 결론

본 프로젝트는 강원 지역 가상 전력설비 주변의 화재위험도를 분석하기 위해, 산불 발생 여부를 직접 확률 예측하는 지도학습 모델이 아니라, **전력설비 주변 위험노출도와 점검 우선순위를 산정하는 DWI 기반 스코어링 모델**을 최종 방법론으로 채택하였다.

최종 위험도는 `0.60 * dwi_pct + 0.25 * static_vulnerability + 0.15 * exposure_risk`로 산정하였고, 이를 전신주 단위로 집계하여 `pole_risk_score`를 계산하였다. 최종적으로 전신주 위험도 상위 5%인 69,390개 전신주를 `decision=1`로 분류하였다.

산불 이력 기반 사후 검증에서는 강원권 산불 발생 위치 주변의 고위험 환경이 random baseline보다 더 높은 빈도와 밀도로 포착되었으며, 가중치 민감도 분석에서도 기준 가중치가 random baseline 대비 안정적인 구분력을 보였다.

또한 ML 기반 SHAP, Lift, Top-K 분석을 보조적으로 활용하여 습도, DWI, 바람, 강수, 지형, 수계 접근성 등 주요 위험 요인의 타당성을 확인하였다. 단, ML 분석은 최종 산식의 직접 가중치 산정 근거가 아니라, 도메인 기반 산식의 변수 구성과 해석 가능성을 보강하는 자료로 활용하였다.

따라서 본 결과는 산불 발생 확률 예측 결과가 아니라, 제한된 점검·순찰 자원을 전력설비 주변 고위험 후보군에 우선 배분하기 위한 의사결정 지원 지표로 활용하는 것이 가장 적절하다.
