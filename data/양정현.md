# XGBoost 모델 성능 검증 결과 보고서

> 작성일: 2026-06-23  
> train: 2020-02, 2021-03 (2개월)  
> valid: 2023-02, 2023-03, 2023-04, 2023-05 (4개월 전체)  
> 평가 기준: 산불 발생일 27일 × 전체 격자 273,001개 기준 일자별 Top-K Recall

---

## 1. 실험 설계

### 1.1 데이터 구성

| 구분 | 기간 | 산불 사건 | 양성 격자 |
|---|---|---|---|
| **train** | 2020-02, 2021-03 (2달) | **7개** | **68건** |
| **valid** | 2023-02 ~ 2023-05 (4달) | **30개** | **313건** |

### 1.2 평가 방식

- **평가 모집단**: 산불 발생일 27일 각각의 **전체 273,001 격자** (샘플링 없음, 가장 엄격한 기준)
- **Top-K Recall**: 일자별 예측 확률 상위 K개 격자 중 실제 산불 발생 격자 포함 비율의 27일 평균
- **비교 대상**: FFDRI 단독, P-FFDRI 단독, XGBoost

### 1.3 XGBoost 모델 설정

| 파라미터 | 값 | 역할 |
|---|---|---|
| n_estimators | 300 | 트리 개수 |
| max_depth | 4 | 과적합 완화 |
| learning_rate | 0.05 | 학습률 |
| scale_pos_weight | 20.0 | 클래스 불균형 보정 |

- **XGBoost가 세 모델 중 가장 낮음** — train 데이터 부족으로 인한 과소학습이 원인
- **P-FFDRI Top-50K 24.6%** — 고위험 후보군 선별에서 P-FFDRI의 실용성 확인

## 3. 원인 분석

### 3.1 XGBoost 성능 저하의 구조적 원인

**train이 7개 사건(68건)에 불과**하여 2023년 valid에서 나타나는 다양한 산불 조건을 커버하지 못했다.

| 원인 | 설명 |
|---|---|
| 과소학습 | 7개 사건으로는 기상·지형·전력설비 복합 패턴 학습 불충분 |
| 연도 도메인 차이 | 2020~2021년과 2023년의 기상 패턴 차이 |
| rn_day_max 과의존 | Feature Importance 1위가 강수량 → train 기간의 특수 패턴에 과적합 |

### 3.2 P-FFDRI가 ML보다 높은 이유

P-FFDRI는 도메인 지식 기반 물리 공식으로 연도·계절에 무관하게 동작한다. train 데이터가 부족한 현재 조건에서는 **지수 방식이 ML보다 일반화에 유리**하다. 이는 데이터가 충분히 확보된 이후 ML의 비선형 패턴 학습 능력이 발휘될 때 역전될 수 있다.

## 6. 본 실험 vs 보고서 V1_2 비교

| 항목 | **본 실험 (XGBoost 파일럿)** | **보고서 V1_2 (RF 전체학습)** |
|---|---|---|
| train 기간 | 2020-02 + 2021-03 (2달) | 2020~2022 전체 |
| train 사건 수 | 7개 | 수백 개 |
| valid/test | 2023 전체 (valid) | 2024 전체 (test) |
| 평가 모집단 | **전체 273,001 격자/일** | feature 존재 샘플(1,527건) |
| 평가 방식 | **엄격** (전수 평가) | 상대적 완화 (샘플 평가) |

두 결과는 **학습 데이터 규모와 평가 기준이 달라 직접 수치 비교 불가**하다.  
본 실험은 XGBoost의 train 데이터 최소 요건을 탐색하는 파일럿 실험으로 해석해야 한다.

## 7. 결론 및 시사점

### 지금 데이터(2달 train)로 알 수 있는 것

1. **P-FFDRI는 학습 없이도 ROC-AUC 0.608, Top-50K 24.6%** — 지수 설계 자체의 타당성 확인
2. **XGBoost는 train 7개 사건으로는 2023년 산불을 일반화하지 못함** — 데이터 부족 한계 명확히 확인
3. **전체 27.3만 격자 기준 Top-K 평가**는 샘플 기반 평가보다 훨씬 엄격하며, 실제 운영 시나리오에 더 가까운 평가 방식임

### 개선 방향

| 우선순위 | 작업 | 기대 효과 |
|---|---|---|
| 1 | 2020~2022 전체 데이터로 train 확장 | 사건 수 수백 개 확보 → 일반화 성능 급상승 예상 |
| 2 | 봄철(2~5월) 한정 학습 | 계절 도메인 일치로 불일치 감소 |
| 3 | P-FFDRI + XGBoost 앙상블 | 지수 안정성 + ML 비선형 패턴 결합 |
| 4 | threshold 최적화 | Recall ≥ 0.5 달성 threshold 탐색 |
